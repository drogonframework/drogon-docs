# نظرة عامة (Overview)

**Drogon** هو إطار عمل لبناء تطبيقات HTTP يعتمد على لغة C++17/20. يمكن استخدام Drogon لبناء مختلف أنواع برامج خوادم تطبيقات الويب بسهولة باستخدام لغة C++.

**Drogon** هو اسم التنين في المسلسل التلفزيوني الأمريكي "Game of Thrones" والذي يعجبني كثيراً.

منصة التشغيل الأساسية لـ Drogon هي Linux، كما أنه يدعم أيضاً أنظمة Mac OS و FreeBSD و Windows.

الميزات الرئيسية لإطار العمل هي كالتالي:

* استخدام مكتبة شبكات ذات إدخال/إخراج اللامُعَطِّل (Non-blocking I/O) تعتمد على epoll (و kqueue تحت macOS/FreeBSD) لتقديم أداء شبكي عالٍ جداً مع تزامن مرتفع (High-concurrency)، يرجى زيارة [نتائج اختبارات TFB](https://www.techempower.com/benchmarks/#section=data-r19&hw=ph&test=composite) لمزيد من التفاصيل.
* توفير نمط برمجة لامتزامن بالكامل (Completely asynchronous programming mode).
* دعم Http1.0/1.1 (على مستوى الخادم والعميل Client/Server).
* بناءً على القوالب (Templates)، تم تنفيذ آلية انعكاس بسيطة (Reflection mechanism) لفصل هيكل البرنامج الرئيسي، والمتحكمات (Controllers)، والعروض (Views) تماماً عن بعضها.
* دعم ملفات تعريف الارتباط (Cookies) والجلسات المدمجة (Built-in sessions).
* دعم العرض من جانب الخادم (Back-end rendering)، حيث يقوم المتحكم بتمرير البيانات إلى العرض لتوليد صفحة Html. يتم وصف العروض عبر ملفات قوالب CSP، وتُضمن أكواد C++ داخل صفحات Html باستخدام وسم CSP. وتتولى أداة Drogon لسطر الأوامر تلقائياً توليد ملفات كود C++ الجاهزة للتجميع (Compilation).
* دعم التحميل الديناميكي لصفحات العرض (التجميع والتحميل الديناميكي أثناء وقت التشغيل Runtime).
* توفير حل توجيه (Routing) مرن ومريح من المسار إلى معالج المتحكم (Controller handler).
* دعم سلاسل الفلاتر (Filter chains) لتسهيل تنفيذ المنطق الموحد (مثل التحقق من تسجيل الدخول، والتحقق من قيود Http Method، وغيرها) قبل معالجة طلبات HTTP.
* دعم https (استناداً إلى OpenSSL).
* دعم WebSocket (على مستوى الخادم والعميل).
* دعم الطلبات والاستجابات بصيغة JSON، مما يجعله صديقاً جداً لتطوير تطبيقات Restful API.
* دعم رفع وتنزيل الملفات.
* دعم الضغط أثناء النقل باستخدام gzip و brotli.
* دعم المعالجة الأنبوبية (Pipelining).
* توفير أداة سطر أوامر خفيفة الوزن، `drogon_ctl`، لتسهيل إنشاء الفئات (Classes) المختلفة في Drogon وتوليد كود العروض.
* دعم القراءة والكتابة اللامتزامنة (Asynchronous) واللامُعَطِّلة (Non-blocking) لقواعد البيانات (قواعد بيانات PostgreSQL و MySQL(MariaDB)).
* دعم القراءة والكتابة اللامتزامنة (Asynchronous) لقواعد بيانات sqlite3 استناداً إلى مجمع الخيوط (Thread pool).
* دعم معمارية ARM.
* توفير تطبيق ORM خفيف ومريح يدعم التعيين ثنائي الاتجاه بين الكائنات وقواعد البيانات (Regular object-to-database bidirectional mapping).
* دعم الإضافات (Plugins) التي يمكن تثبيتها عبر ملف الإعدادات عند وقت التحميل.
* دعم البرمجة موجهة الجوانب (AOP) مع نقاط انضمام (Joinpoints) مدمجة.
